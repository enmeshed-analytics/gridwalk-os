Loading an OSM Base Map into PostGIS with osm2pgsql
=====================================================

1. Install osm2pgsql

   macOS:
     brew install osm2pgsql

   Ubuntu/Debian:
     sudo apt install osm2pgsql

2. Download an OSM data file (.osm.pbf)

   Browse extracts at https://download.geofabrik.de/ and download a region.
   For example, to get Great Britain:

     curl -L -O https://download.geofabrik.de/europe/great-britain-latest.osm.pbf

3. Load the data into PostGIS

   Using the default docker-compose credentials (admin / password):

   PGPASSWORD=password osm2pgsql -d gridwalk \
     -H localhost \
     -P 5432 \
     -U admin \
     -s \
     great-britain-latest.osm.pbf

   Flags:
     -d   database name
     -H   host
     -P   port
     -U   user
     -s   slim mode (uses less RAM, recommended for large files)

   One-liner:

     PGPASSWORD=password osm2pgsql -d gridwalk -H localhost -P 5432 -U admin -s great-britain-latest.osm.pbf

   This creates tables: planet_osm_point, planet_osm_line, planet_osm_polygon, planet_osm_roads
   in the public schema of the target database.
